1. 목적

레토 업로더(이하 ‘앱’)는 채널 ‘이슈여행자 레토’ 운영자가 직접 제작한 영상을 운영자 본인의 YouTube 채널과 Instagram 계정에 업로드·예약 게시하기 위한 내부 도구입니다.

2. 이용하는 정보

앱은 운영자 본인이 허용한 범위(YouTube Data API의 동영상 업로드·관리, Instagram 콘텐츠 게시)에서만 운영자 계정에 접근합니다. 영상 파일, 제목, 설명, 썸네일 등 운영자가 직접 만든 게시물 정보만 다룹니다.

3. 수집하지 않는 정보

앱은 시청자나 다른 사용자의 개인정보를 수집·저장·공유하지 않습니다. 운영자 외의 다른 사람은 앱을 사용할 수 없습니다.

4. 보관과 보안

인증 정보는 운영자의 비공개 작업 환경에만 보관되며, 제3자에게 판매하거나 제공하지 않습니다. 운영자는 언제든지 Google 계정의 서드파티 액세스 또는 Instagram 설정에서 앱의 접근 권한을 철회할 수 있습니다.

5. Google API 서비스 사용자 데이터 정책

앱이 Google API로부터 받은 정보의 사용과 전송은 제한적 사용 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 준수합니다. YouTube API 서비스를 이용하며, YouTube 서비스 약관과 Google 개인정보처리방침이 함께 적용됩니다.
